# KMP Interactive Learning Lab

## Purpose
Interactive teaching artifact for the Knuth–Morris–Pratt (KMP) Pattern Matching Algorithm.

## Run
Extract the ZIP and open `index.html` in Chrome, Safari, or Edge. No installation/backend is required.

## Learning flow
Learn the problem → build LPS → run interactive KMP visualisation with custom text/pattern → inspect Python implementation and complexity → complete quiz and mini challenge.

## Complexity
LPS preprocessing: O(m)
Search: O(n)
Overall: O(n + m)
Space: O(m)

## Files
index.html — learning content and interface
style.css — design
script.js — LPS/KMP logic, visualisation and quiz
