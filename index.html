🎯 The problem

Given a text and a pattern, find where the pattern occurs in the text.

Text: ABABDABACDABABCABAB
Pattern: ABABCABAB

Naive approach

After a mismatch, it may repeat comparisons from the beginning.

KMP approach

Reuse information from the pattern so we do not restart unnecessarily.

💡 Key idea: LPS

LPS = Longest Proper Prefix which is also a Suffix.

It tells KMP how much of the pattern can be reused after a mismatch.

🧩 Build the LPS array

Enter a pattern and generate its LPS values.

Example: In ABAB, “AB” is both a prefix and suffix, so LPS = 2.

🐍 Python implementation

def compute_lps(pattern):
    lps = [0] * len(pattern)
    length = 0
    i = 1
    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length:
            length = lps[length - 1]
        else:
            lps[i] = 0
            i += 1
    return lps

def kmp_search(text, pattern):
    lps = compute_lps(pattern)
    i = j = 0
    matches = []
    while i < len(text):
        if text[i] == pattern[j]:
            i += 1; j += 1
            if j == len(pattern):
                matches.append(i - j)
                j = lps[j - 1]
        elif j:
            j = lps[j - 1]
        else:
            i += 1
    return matches

Time

O(n + m): LPS is O(m), search is O(n).

Space

O(m): the LPS array stores m values.
